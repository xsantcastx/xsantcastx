# Eclipse Realms — Item Lore Codex (Proposal)

**Status:** Proposed lore for existing approved item masters. This is not an economy, inventory, crafting, balance, or asset-integration specification.

## Scope and rules

This codex covers every current master under `Assets/Items/` and the twelve approved masters in `Assets/Characters/equipment/`. It deliberately excludes Currencies, Market listings, UI controls, and source/reference exports. All names and lore are provisional until owner approval.

An item’s lore must describe a contradiction or consequence, not only an effect. Specific values, prices, rarity, damage, ownership rules, recipes, and rewards remain out of scope.

## Design handoff

For every future item, add a stable asset path, a one-sentence contradiction, a realm or cross-realm relationship, and an inspectable source or consequence. Do not create a lore description that requires a new mechanical stat or a new saved field until a separate product and state review approves it.
