# Systems map — read once, then open files directly (don't search)

Paths are under `src/app/` unless they start with `docs/`, `e2e/`, `scripts/`. Handoffs are `docs/handoff/<name>.md`.
Play specs are `e2e/play-<name>.spec.ts` (helpers: `e2e/play-helpers.ts`, `e2e/play-delve-fixtures.ts`).
Tip: each system keeps its player text in a sibling `*.i18n.ts` (lazy table, EN + ES), and its save blob in a `*-save.model.ts`.
