# Named unique items (I1 pixel icons)

Folder: `Assets/Items/ArtBible/<Family>/`. Pixel scale, palettes and the export rules are in the art bible, [docs/art/style-guide.md](../../art/style-guide.md); the save checklist is in [../README.md](../README.md). Paste **Prompt** as the positive prompt and **Negative** as the negative prompt, then clean the result on the art-pixel grid (style guide §14). The spec line is the export contract.

Rarity is shown by the slot rim and the name colour (style guide §5.4), never by an aura in the icon.
